# Contributing to GSNotes

Thanks for your interest!

1. Open an issue describing the bug or feature before large changes.
2. Fork, create a branch (`feature/<short-name>`), and keep commits focused.
3. Never commit secrets, API keys, or personal data.
4. Update `CHANGELOG.md` under an *Unreleased* heading.
5. Open a pull request using the template.

By contributing you agree your contributions are licensed under the project's license.
